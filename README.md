# Anands Fino

AI research and signal desk for forex and metals, executing through MetaTrader 5 (running under Wine in the same stack).
FreeLLMAPI does the volume work (tagging news). **Claude gives the final YES or NO on every trade.**
Hard risk limits live in code and Claude cannot override them.

## Flow (hourly, on candle close)
data → technicals → research (FRED, CFTC, calendar, news) → weighted score (7 factors) → risk gate → **Claude YES/NO** → gate re-check → execute / ask approval → journal.

## Deploy on Coolify
1. In the existing **Anands Fino** app set Build Pack to **Docker Compose**, branch `main`, compose location `/docker-compose.yaml`.
2. Domains: `app` → port **8000**, `mt5` → port **3000** (MT5 web desktop). Do not publish 8001.
3. Environment variables: `ANTHROPIC_API_KEY`, `FREELLMAPI_BASE_URL`, `FREELLMAPI_KEY`, `FRED_API_KEY`. `ADMIN_PASSWORD`, the MT5 desktop password and the DB password are generated by Coolify (see the app's variables).
4. Deploy. The MT5 image is about 4 GB, first start takes several minutes. Needs x86_64 and about 2 GB free RAM.
5. Open the MT5 domain, log in, then in MT5 log in to a **DEMO** account (File → Login to Trade Account). Enable algo trading.
6. Open `https://<app domain>/api/diagnostics`. Check the bridge, account type, symbol names and candle counts. Broker symbols with suffixes (e.g. `XAUUSD.m`) go in `SYMBOL_MAP` as JSON.

## Autonomy levels
`research` (analysis only) · `alerts` (signal + webhook) · `demo_auto` (default, trades only a demo account) · `live_approval` · `live_auto`.
Live levels need `ALLOW_LIVE=true`; a real account is refused otherwise.

## Risk gate (code, not model)
0.5% risk per trade, 2% daily loss cap, max 3 open trades, min R:R 1.5, spread ≤ 10% of stop, Claude confidence ≥ 0.6, halt after 5 straight losses, ±15 min news blackout, one open trade per symbol, no same-direction trades in correlated pairs, lots rounded down to the broker step.

## Honest status
- Logic, gate, scoring and API are covered by tests against a mock broker (`pytest`).
- **Not yet verified against a live terminal:** the MT5 RPyC bridge client and the CFTC report parsing. Use `/api/diagnostics` first and stay on demo until you have watched several days of fills.
- This is not financial advice; no strategy is guaranteed profitable.
